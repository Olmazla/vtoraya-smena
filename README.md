# Вторая смена – учебный интернет-магазин

Учебный проект по электронной коммерции: бренд сумок и аксессуаров из переработанных материалов (рекламные баннеры, велокамеры, грузовые тенты, ремни безопасности).

Сайт: https://olmazla.github.io/vtoraya-smena/

Один файл `index.html` без сборки, фото товаров – в `img/` (Unsplash): каталог с фильтрами, карточки с вариантами и наличием, корзина, оформление заказа с расчётом доставки, условия оплаты, доставки и возврата. Заказы никуда не отправляются.
